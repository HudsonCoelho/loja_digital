# Loja Digital

Sistema web para gestão de vendas, estoque e relatórios, desenvolvido em Python (Flask) por Hudson Coelho.

## Funcionalidades
- Dashboard com visão geral
- Cadastro e edição de produtos
- Controle de estoque
- Registro de vendas
- Relatórios e gráficos
- Configurações personalizáveis

## Como executar
1. Instale as dependências:
   ```
   pip install -r requirements.txt
   ```
2. Execute o sistema:
   ```
   python app.py
   ```
3. Acesse no navegador: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## Estrutura
- `app.py`: Código principal
- `templates/`: Páginas HTML
- `static/`: Imagens e arquivos estáticos
- `estoque.db`: Banco de dados SQLite
- `requirements.txt`: Dependências
